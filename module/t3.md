Du hast die Selbstkosten des Business Deluxe: **108,60 €**. Jetzt fehlt der **Preis**, den der Kunde zahlt.

## 1. Gewinn, Skonto und Rabatt

| Zeile | Bedeutung | Prozentsatz bezogen auf |
| --- | --- | --- |
| + Gewinnzuschlag 20 % | Aufschlag auf die Selbstkosten | **vom Hundert** (Selbstkosten = 100 %) |
| = Barverkaufspreis | | |
| + Kundenskonto 3 % | Nachlass bei Zahlung innerhalb von 14 Tagen | **im Hundert** (Zielverkaufspreis = 100 %) |
| = Zielverkaufspreis | | |
| + Kundenrabatt 10 % | Nachlass bei Abnahme ab 50 Stück | **im Hundert** (Listenverkaufspreis = 100 %) |
| = Listenverkaufspreis (netto) | | |

:::achtung Typischer Fehler
Skonto und Rabatt rechnest du **nicht** einfach als Prozent vom Barverkaufspreis. Der Kunde zieht sie vom **höheren** Preis ab. Deshalb rechnet man rückwärts: Der Barverkaufspreis ist 97 % des Zielverkaufspreises, der Zielverkaufspreis 90 % des Listenverkaufspreises.
:::

:::tipp Beispiel „im Hundert“
Zielverkaufspreis = 100 %, Skonto 3 % → Barverkaufspreis = 97 %.

Zielverkaufspreis = Barverkaufspreis ÷ 97 × 100, oder: Barverkaufspreis ÷ 0,97.

Mit 130,32 € Barverkaufspreis: 130,32 € ÷ 0,97 = **134,35 €**. Das Skonto ist 134,35 € − 130,32 € = 4,03 €.
:::

:::aufgabe basis 25 1 · Zum Listenverkaufspreis rechnen
Führe das Schema weiter: Gewinnzuschlag (20 % vom Hundert auf die Selbstkosten), Skonto (3 % im Hundert), Rabatt (10 % im Hundert). Runde jede Zeile auf zwei Dezimalstellen.

:::checkliste Selbstcheck
- Der Gewinn bezieht sich auf die Selbstkosten.
- Skonto und Rabatt habe ich mit ÷ 0,97 und ÷ 0,90 berechnet.
- Der Listenverkaufspreis liegt bei etwa 149 €.
:::

:::loesung Lösung
| Zeile | Betrag | Bemerkung |
| --- | --- | --- |
| Selbstkosten | 108,60 € | |
| + Gewinnzuschlag | 21,72 € | 20 % vom Hundert (von Selbstkosten) |
| = Barverkaufspreis | 130,32 € | |
| + Kundenskonto | 4,03 € | 3 % im Hundert (vom Zielverkaufspreis): 130,32 € ÷ 0,97 = 134,35 € |
| = Zielverkaufspreis | 134,35 € | |
| + Kundenrabatt | 14,93 € | 10 % im Hundert (vom Listenverkaufspreis): 134,35 € ÷ 0,90 = 149,28 € |
| = Listenverkaufspreis (netto) | **149,28 €** | |
:::
:::

:::aufgabe basis 10 2 · Probe und Einordnung
1. **Probe:** Ein Händler kauft 60 Stück (Rabatt) und zahlt in 10 Tagen (Skonto). Rechne vom Listenverkaufspreis (149,28 €) zurück: Welchen Preis je Stück zahlt er? Stimmt das mit dem Barverkaufspreis überein?
2. Die Rucksäcke der Montelli GmbH kosten laut Artikelliste meist 149,00 € (z. B. Nordwind, Sahara, Explorer). Was sagt dir dein Ergebnis?

:::loesung Lösung
1. 149,28 € − 10 % Rabatt = 134,35 €, davon 3 % Skonto abgezogen = **130,32 €**. Das ist der Barverkaufspreis. Die Kalkulation geht auf.
2. Der Preis liegt fast genau bei 149 €. Er deckt alle Kosten, Gewinn, Skonto und Rabatt. Ob der Markt den Preis akzeptiert, klären die Teile 2 bis 4 der Reihe Preispolitik (konkurrenz-, nachfrageorientiert).
:::
:::

:::aufgabe plus 10 3 · Mehr Gewinn?
Die Geschäftsleitung möchte 25 % Gewinn statt 20 %. Wie hoch wird dann der Listenverkaufspreis? Runde jede Zeile auf zwei Dezimalstellen.

:::loesung Lösung
Gewinn 25 % von 108,60 € = 27,15 €, Barverkaufspreis 135,75 €. Zielverkaufspreis 135,75 € ÷ 0,97 = 139,95 €. Listenverkaufspreis 139,95 € ÷ 0,90 = **155,50 €**.
