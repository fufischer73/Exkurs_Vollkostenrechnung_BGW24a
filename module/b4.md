Für Material und Fertigung hast du die Sätze. Es fehlen noch **Verwaltung** und **Vertrieb**. Sie arbeiten für alle Rucksäcke und lassen sich weder auf Material noch auf Löhne beziehen. Als Grundlage nimmt man die **Herstellkosten**.

## 1. Die Herstellkosten ermitteln

In einer **Nebenrechnung** fasst du alles zusammen, was bis zur fertigen Ware angefallen ist:

| Zeile | Inhalt |
| --- | --- |
| Fertigungsmaterial | Einzelkosten |
| + Materialgemeinkosten (MGK) | Fertigungsmaterial × MGK-Satz |
| **= Materialkosten** | |
| Fertigungslöhne (Handarbeit) | Einzelkosten |
| + Fertigungsgemeinkosten (FGK) | Löhne × FGK-Satz |
| **= Fertigungskosten I** | |
| Maschinenabhängige Fertigungsgemeinkosten | Maschinenstunden × Maschinenstundensatz |
| + Fertigungslöhne des Maschinenplatzes | Einzelkosten |
| + Restgemeinkosten | Maschinenplatzlöhne × Restgemeinkosten-Satz |
| **= Fertigungskosten II** | |
| **= Herstellkosten der Erzeugung** | Materialkosten + Fertigungskosten I + II |
| + Bestandsminderungen / − Bestandsmehrungen | in Juli: keine |
| **= Herstellkosten des Umsatzes** | |

:::notiz Bestandsveränderungen
Wird in einem Monat mehr hergestellt als verkauft (Bestandsmehrung), landen Teile der Herstellkosten im Lager und gehören noch nicht zum Umsatz. Wird mehr verkauft als hergestellt (Bestandsminderung), kommen Herstellkosten früherer Monate dazu. **In unserem Beispiel gibt es keine Bestandsveränderungen.** Die Herstellkosten des Umsatzes sind deshalb gleich den Herstellkosten der Erzeugung.
:::

## 2. Verwaltungs- und Vertriebsgemeinkosten

- **VwGK-Zuschlagssatz** = Gemeinkosten Verwaltung × 100 ÷ Herstellkosten des Umsatzes
- **VtGK-Zuschlagssatz** = Gemeinkosten Vertrieb × 100 ÷ Herstellkosten des Umsatzes

:::tipp
In der Lernsituation steht ein gemeinsamer Satz „Verwaltungs- und Vertriebsgemeinkosten 20 %“. Du berechnest beide Sätze getrennt und kannst sie addieren. Dann siehst du, wie der gemeinsame Satz entsteht.
:::

:::aufgabe basis 25 1 · Herstellkosten und Sätze für Juli
1. Erstelle die **Nebenrechnung** für Juli. Nutze die Sätze aus B2 und B3 und diese Bezugsgrößen: Fertigungsmaterial 200.000 €, Fertigungslöhne Handarbeit 62.500 €, Maschinenstunden 1.000 h, Maschinenplatzlöhne 14.000 €. Die Gemeinkosten kannst du auch direkt aus dem BAB übernehmen.
2. Berechne den **VwGK-Zuschlagssatz** und den **VtGK-Zuschlagssatz** (zwei Dezimalstellen).
3. Addiere beide Sätze. Wie weit liegt die Summe von den 20 % der Lernsituation entfernt?

:::checkliste Selbstcheck
- Die Herstellkosten der Erzeugung stimmen mit der Summe der Zeilen überein.
- Ich habe keine Bestandsveränderungen eingerechnet.
- Verwaltung und Vertrieb habe ich auf die Herstellkosten bezogen, nicht auf Material oder Löhne.
:::

:::loesung Lösung
| Zeile | Betrag |
| --- | --- |
| Fertigungsmaterial | 200.000,00 |
| + MGK 39.400 | 39.400,00 |
| = Materialkosten | 239.400,00 |
| Fertigungslöhne (Handarbeit) | 62.500,00 |
| + FGK 50.625 | 50.625,00 |
| = Fertigungskosten I | 113.125,00 |
| Maschinenabhängige GK (1.000 h × 81 €) | 81.000,00 |
| + Fertigungslöhne Maschinenplatz | 14.000,00 |
| + Restgemeinkosten (30 % von 14.000) | 4.200,00 |
| = Fertigungskosten II | 99.200,00 |
| **Herstellkosten der Erzeugung** | **451.725,00** |
| Bestandsveränderungen | 0,00 |
| **Herstellkosten des Umsatzes** | **451.725,00** |

VwGK: 56.000 × 100 ÷ 451.725 = **12,40 %** · VtGK: 35.700 × 100 ÷ 451.725 = **7,90 %** · Summe **20,30 %** (Lernsituation: 20 %, also fast gleich).
:::
:::

:::aufgabe plus 10 2 · Bestandsmehrung
Angenommen, im Juli wären Rucksäcke zu Herstellkosten von **20.000 €** auf Lager gegangen (Bestandsmehrung). Wie hoch wären dann die Herstellkosten des Umsatzes und der VwGK-Satz? Was ändert sich?

:::loesung Lösung
Herstellkosten des Umsatzes: 451.725 € − 20.000 € = **431.725 €**. VwGK: 56.000 × 100 ÷ 431.725 = **12,97 %**. Der Satz steigt, weil weniger verkauft wurde, die Verwaltungskosten aber gleich geblieben sind.
:::
:::
