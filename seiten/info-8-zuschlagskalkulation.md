## Das Kalkulationsschema

Die **Zuschlagskalkulation** führt von den Einzelkosten eines Produkts über die Gemeinkosten zu den Selbstkosten und weiter zum Verkaufspreis:

| Zeile | Berechnung |
| --- | --- |
| Fertigungsmaterial | Einzelkosten |
| + Materialgemeinkosten | MGK-Satz auf das Fertigungsmaterial |
| **= Materialkosten** | |
| Fertigungslöhne | Einzelkosten (Handarbeit) |
| + Fertigungsgemeinkosten | FGK-Satz auf die Fertigungslöhne |
| **= Fertigungskosten I** | |
| Maschinenabhängige Fertigungsgemeinkosten | Maschinenstunden × Maschinenstundensatz |
| + Fertigungslöhne des Maschinenplatzes | Einzelkosten |
| + Restgemeinkosten | Satz auf die Löhne des Maschinenplatzes |
| **= Fertigungskosten II** | |
| **= Herstellkosten** | Materialkosten + Fertigungskosten I + II |
| + Verwaltungs- und Vertriebsgemeinkosten | Satz auf die Herstellkosten |
| **= Selbstkosten** | |
| + Gewinnzuschlag | vom Hundert auf die Selbstkosten |
| **= Barverkaufspreis** | |
| + Kundenskonto | im Hundert |
| **= Zielverkaufspreis** | |
| + Kundenrabatt | im Hundert |
| **= Listenverkaufspreis (netto)** | |

Sondereinzelkosten (zum Beispiel Fracht für einen einzelnen Auftrag) kämen in einer eigenen Zeile dazu. Hier fallen sie nicht an.

## „Vom Hundert“ und „im Hundert“

- **Vom Hundert:** Der Anfangswert ist 100 %. Der Zuschlag wird auf ihn gerechnet. Beispiel: Gewinn 20 % auf die Selbstkosten.
- **Im Hundert:** Der **höhere Endwert** ist 100 %. Der Abzug (Skonto, Rabatt) bezieht sich auf ihn. Deshalb rechnet man rückwärts mit **÷ (1 − Satz)**.

| Zeile | Rechnung |
| --- | --- |
| Zielverkaufspreis | Barverkaufspreis ÷ (1 − Skontosatz) |
| Listenverkaufspreis | Zielverkaufspreis ÷ (1 − Rabattsatz) |

## Beispiel mit anderen Zahlen

Selbstkosten 200,00 €, Gewinn 10 %, Skonto 2 %, Rabatt 5 %.

| Zeile | Rechnung | Betrag |
| --- | --- | --- |
| Selbstkosten | | 200,00 € |
| + Gewinn | 10 % von 200,00 € | 20,00 € |
| = Barverkaufspreis | | 220,00 € |
| + Skonto | Zielverkaufspreis = 220,00 € ÷ 0,98 = 224,49 € | 4,49 € |
| = Zielverkaufspreis | | 224,49 € |
| + Rabatt | Listenverkaufspreis = 224,49 € ÷ 0,95 = 236,31 € | 11,82 € |
| = Listenverkaufspreis | | 236,31 € |

**Probe:** 236,31 € − 5 % Rabatt ≈ 224,49 €, davon 2 % Skonto abgezogen ≈ 220,00 €.
